# Портфолио Татьяны Хлебко

Живой сайт: <https://mario-amazing.github.io/tatiana-portfolio/>
Публикуется через GitHub Pages из ветки `main`, индексация поисковиками закрыта
(`noindex` в странице и `robots.txt`).

## Что где

| Путь | Что это |
|------|---------|
| `index.html` | собранная страница, её и отдаёт Pages. Руками не править — пересобирается из шаблона |
| `clips/` | ролики и постеры к ним: `m*` — массаж, `c*` — кондитерские, `o*` — другие |
| `build/template.html` | исходный шаблон страницы: вся вёрстка и тексты |
| `build/build.py` | сборка `index.html` из шаблона |
| `build/assets/` | шрифты, портрет и скриншот сайта — вшиваются в страницу |
| `build/resume.md` | текст резюме, из него собирается docx |
| `source/` | оригиналы из телеграма, в гит не входят |

## Как обновить страницу

```bash
python3 build/build.py          # правки текста — в build/template.html
git add -A && git commit -m "..." && git push
```

Pages пересобирается сама, обычно за минуту-две.

## Как обновить резюме

```bash
pandoc build/resume.md -o ~/Desktop/tatiana-portfolio/Хлебко_Татьяна_SMM_контент.docx
```

## Про ролики

Одиннадцать роликов лежат ровно такими, какими их прислала Танюша. Четыре самых
тяжёлых (были 73, 45, 42 и 32 МБ) перекодированы в исходном разрешении 1080x1920
так, чтобы каждый уложился в 30 МБ: `m2`, `c1`, `c2`, `o3`. Их оригиналы — в `source/`.
